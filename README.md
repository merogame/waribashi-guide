# 割りばしガイド

[ガイドを開く](https://merogame.github.io/waribashi-guide/)

二人対戦の割りばしゲームで、自分が出す手を案内するガイドです。上部に相手の左右の手、中央に推奨手、下部に自分の左右の手を表示します。自分の指の本数は表示のみです。

## 使い方

1. 自分が「先手」か「後手」かを選びます。両者の左右の手は、それぞれ1本から始まります。
2. 自分の番では、中央の推奨手を実際に出してから中央をタップすると、指の本数を更新して相手の番に進みます。
3. 相手の番では、相手が使った手を押します。こちらを攻撃した場合は、中央に出る「自分 左」「自分 右」で攻撃された手を入力します。相手が自分自身の手を攻撃した場合は、相手側の2つの手を順に押します。
4. 相手が分けた場合は、相手の生きている手、死んでいる手の順に押し、中央に表示される分け方を選びます。「1・3」は、相手の左1本・右3本を表します。自分が分ける場合は、中央の推奨手をタップして進みます。
5. 両手が0になると「勝ち」「負け」を表示します。中央をタップすると先手・後手の選択に戻ります。

左右は、それぞれの人自身から見た左手・右手を表します。自分の番では中央の推奨手だけで進みます。使えない手や操作のボタンは無効になります。

右上の「↶」で1手戻せます。途中まで手を選択している場合は、選択を取り消します。過去128手まで戻せます。推奨手は同じ手番の間は固定され、戻した際もその手番の推奨手を復元します。再読み込みすると最初の選択画面に戻ります。

## ルール

- 二人が交互に1回ずつ操作します。
- 生きている手で、相手の生きている手、または自分のもう片方の生きている手を攻撃できます。
- 攻撃された手に、攻撃に使った手の本数を足します。攻撃に使った手の本数は変わりません。
- 合計が5なら0になり、その手は死にます。5を超えると余りが残ります。例えば4＋4は3になります。
- 片手が0、もう片手が2〜4のときだけ、合計を保ったまま両手が1以上になるように分けられます。

| 分ける前 | 分けた後の左・右 |
|---|---|
| 片手0・もう片手2 | 1・1 |
| 片手0・もう片手3 | 1・2、2・1 |
| 片手0・もう片手4 | 1・3、2・2、3・1 |

「0・1」を「1・0」にするなど、左右を入れ替えるだけの操作はできません。両手が生きている場合は分けられません。死んだ手の復活は分ける操作で行います。先に両手が0になった人が負けです。同じ局面を繰り返しても対戦は続行します。

## 推奨手

手番の人の左右2つの手と相手の左右2つの手から、局面ごとの最善の結果を求めます。勝敗が決まった局面から逆向きに調べ、勝ちを強制できる局面、負けを強制される局面、両者が負けを避けて続行できる局面を分類します。勝敗の分類と手数は整数で計算します。

推奨する候補は次の基準で絞ります。

- 勝てる局面：相手が最善を尽くしても、最短で勝てる手。
- 決着を避けられる局面：負けを強制されない手。
- 必敗の局面：相手が最善を尽くした場合の、負けまでの手数を最も延ばせる手。

同じ条件を満たす手が複数あれば、候補の中から均等に抽選します。候補が2手なら各50%、3手なら各1/3です。相手の履歴やミスの起こりやすさに応じた重み付けは行いません。抽選には `crypto.getRandomValues` と余りの偏りを除く処理を使います。

このルールの初期状態では、双方が最善を続けると決着を避けられます。対戦中に勝ちを強制できる局面になれば、その勝ち筋を推奨します。続行できる局面でも、画面上で自動的に引き分けにはしません。

継続中の全576局面について、合法手、勝敗分類、最善の手数、推奨候補を検証しています。別の合法手生成処理と、手数を増やしながら調べる別の計算方法でも照合しています。

## 構成

- `index.html`：ガイドのページ。
- `割りばしガイド.html`：保存用。`index.html` と同じ内容です。
- `README.md`：この説明。
- `.nojekyll`：静的ファイルをそのまま配信する設定。
- `tools/verify-strategy.mjs`：ルールと推奨手の検証。
- `tools/verification.json`：検証結果。

HTMLは約12.1KBです。読み込み時に小さな戦略表を計算してページ内に保持し、対戦中はその表を使います。HTMLを保存すれば直接ブラウザで開いて使えます。外部ライブラリ、外部フォント、画像、サーバー処理、戦略表の追加ダウンロードは使いません。入力した手や対戦履歴を保存・送信する処理もありません。

画面は一画面に収め、ページ内のピンチ、ダブルタップ、ホイール、拡大ショートカットを抑止しています。ブラウザ自身の設定やアクセシビリティ機能による拡大は、ページから完全には禁止できません。

検証はNode.jsで `node tools/verify-strategy.mjs` を実行すると再現できます。
